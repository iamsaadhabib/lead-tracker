# Lead Tracker

A simple, fast lead tracking dashboard that runs in the browser with no setup. Add leads, move them through your pipeline, search and filter, and export everything to CSV.

Built by **Saad Habib**, Founder of [Fivup Leads](https://fivupleads.com).

## Features

- Add leads with name, company, email, source and status
- Pipeline stages: New, Contacted, Qualified, Won, Lost
- Live stats: total leads, count per stage and win rate
- Search by name or company, filter by status
- Export all leads to CSV
- Data saved in the browser (localStorage), nothing leaves your device
- Responsive layout that works on mobile

## Tech

HTML, CSS and vanilla JavaScript in a single file.

## Run it

Download `index.html` and open it in any browser.

## Live demo (GitHub Pages)

1. Open the repository **Settings**, then **Pages**.
2. Under **Branch**, select `main` and `/ (root)`, then **Save**.
3. After a minute your demo is live at `https://<your-username>.github.io/lead-tracker/`.
